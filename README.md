# Hockey-Salary-vs-Performance-Analysis
This project analyzes the relationship between NHL player salary and offensive performance using Python, pandas and matplotlib.

## Dataset
- NHL player dataset containing salary and production statistics
- Key fields used in this analysis:
  - Salary
  - Points
  - Goals
  - Assists
  - Games Played
  - Points Per Game

## Analysis Performed
- Checked for missing and duplicate values
- Removed irrelevant contract clause data
- Cleaned and converted salary data from string format to numeric format
- Generated summary statistics for salary and production metrics
- Measured the correlation between salary and points per game
- Visualized salary vs. performance trends
- Compared the top 10 highest-paid players by points per game

## Key Findings
- There is a strong positive correlation between salary and points per game
- Higher-paid players generally tend to produce more offensively
- There are still noticeable outliers, with some players outperforming or underperforming relative to salary

## Technologies Used
- Python
- pandas
- matplotlib
